# 2. RPE System

## Resistance Training

| RPE | Approx. reps in reserve |
|---:|---:|
| 6 | 4+ |
| 7 | 3 |
| 7.5 | 2–3 |
| 8 | ~2 |
| 8.5 | ~1–2 |
| 9 | ~1 |
| 10 | 0 / technical failure |

For calisthenics skill work, **technical failure** means the position or movement standard breaks.

Examples:
- Front lever hips drop → set ends.
- HSPU ROM shortens or line collapses → set ends.
- Ring dip loses stable depth or lockout → set ends.

Do not turn prescribed RPE 8 work into RPE 10 work because you feel good.

## Flexibility RPE

| RPE | Meaning |
|---:|---|
| 5 | Easy |
| 6 | Clear stretch, fully controlled |
| 7 | Strong but comfortable |
| 7.5 | Strong end-range work, still relaxed |
| 8+ | Not required |

Progress flexibility through:

> **More usable ROM → better control → modest external load**

not by tolerating more pain.

# 3. Block Structure

| Phase | Weeks | Goal |
|---|---:|---|
| Re-entry | **1–2** | Establish post-break baseline around RPE 8 |
| Accumulation | **3–5** | Gradually increase sets / difficulty |
| Deload | **6** | Reduce volume ~40–50%, RPE 6–7 |
| Intensification | **7–10** | Harder leverage / heavier loading |
| Realization | **11** | Highest-quality hard work without failure |
| Consolidation / benchmark | **12** | Lower volume and compare progress |

During a cut, maintaining absolute strength while losing ~7 kg is a major success because relative strength rises substantially.

# 10. Cut-Specific Autoregulation

The target of **80 kg → ~73 kg in 12 weeks** is a meaningful cut.

Reduce load/volume that day if:
- the first work set is ~1 RPE above prescription;
- performance falls >10–15% across sets;
- multiple nights of poor sleep accumulate;
- joints/tendons become progressively irritated;
- bodyweight is dropping much faster than intended and strength is falling.

Do not compensate for poor recovery by:
- training to failure;
- adding unscheduled sets;
- turning Sunday cardio into a race;
- testing HSPU/front lever every week.

# 11. What Counts as Progress

Progress can mean:
- same weighted dip at lower bodyweight;
- same weighted pull-up at lower bodyweight;
- harder HSPU leverage;
- greater HSPU ROM;
- less wall assistance;
- harder front-lever progression;
- less band assistance;
- better lever body line;
- stronger dragon flag / rollout / wiper;
- deeper pancake / splits / pike;
- greater cardio output at the same RPE.

The goal is not large muscle gain during this cut.

The target is:

> **Retain almost all muscle and absolute strength while improving relative strength, skill efficiency, body composition, flexibility and cardiovascular fitness.**

# 13. Cardio Protocol Note

This cardio framework is **adapted from Andrew Huberman's fitness guidance**, rather than copying his weekly schedule exactly.

Huberman has described a general fitness setup that includes three distinct cardiovascular sessions:
- one longer, slower endurance session;
- one shorter, somewhat faster ~25–30 minute session;
- one short high-intensity interval session.

His Foundational Fitness Protocol also explicitly allows the schedule to be modified around individual goals and recovery.

Here, those principles are adapted around a five-day calisthenics/strength split so that cardio stays supportive rather than becoming the main training stress.
